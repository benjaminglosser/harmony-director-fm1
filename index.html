Firmware v2.2 • M-VAVE FM-1

Harmony Director for FM-1

Dedicated rehearsal podium firmware for the M-VAVE FM-1 synthesizer: polyphonic drones, live-switchable Equal & Pure Just Intonation, C / B♭ / E♭ / F transposition, and a Boss DB-90 style Dr. Beat metronome with adaptive drum grooves.

Install on Your FM-1

Recommended • Personal Mac / Windows PC

Option 1: M-Flasher + Recovery Bootloader

Stock FM-1 units have no physical rescue button. Installing m-bootloader first adds brick protection and saves a verified backup of your factory firmware.

  1. Download M-Flasher and m-bootloader.
  2. Connect your powered-on FM-1 directly via USB data cable and click DOWNLOAD MODE (click Ignore if macOS warns about an unreadable disk).
  3. Click Back up the whole flash to keep a safe factory restore copy, then install m-bootloader.
  4. Click Install firmware (.fwsc), select HarmonyDirector-FM1-v2.2.fwsc, wait for 100%, and power-cycle.

Quick Install • School Laptop / Chromebook

Option 2: One-Click Web Installer

No software downloads or admin rights required. Works directly in Google Chrome or Microsoft Edge (Safari is not supported).

  1. Plug your powered-on FM-1 directly into your computer with a USB data cable (avoid unpowered USB hubs).
  2. Open the Web Installer below and click Allow when prompted for MIDI / SysEx access.
  3. Click Install and keep the browser tab in front without touching the cable until verification reaches 100%.
  4. Switch the FM-1 off and back on.
Open Web Installer
Note during Web Install: Because this firmware is built on the Felucca open-source hardware layer, the Web Installer and your computer's USB list will show the device port as Felucca or FM-1_900. That is normal—it installs Harmony Director v2.2 directly.
